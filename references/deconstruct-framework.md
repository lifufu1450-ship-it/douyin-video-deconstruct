# 抖音短视频 11 字段模版拆解卡规范

拆片必须严格基于**真实转写的逐字稿**、**实际画面呈现方式**以及**页面可见公开数据**，严禁编造文案或虚构互动数据。

---

## 一、强制输出样式（11 个固定字段，严禁增删板块，必须使用规范 Markdown 排版防合并）

> **Markdown 排版铁律（极其重要）**：聊天界面按标准 Markdown 渲染，单个 `\n` 会被合并成同一段落！因此：
> - 每个字段之间**必须空一行**（`\n\n`），字段名加粗（如 `**模版名称：**`）；
> - `拆片演示` 中每个模块标题**必须加粗并独立成段**（如 `**1. 痛点开篇：**`）；
> - 逐句短句换行必须在每行末尾加**两个空格**（硬换行 `  \n`）或用空行分段，确保渲染出来每一句都清清楚楚独立成行，绝不粘连成一坨！

默认严格输出以下 11 个固定字段，不附加“拍摄长篇分析”“剪辑拆解”“逐镜表格”“改写脚本”或多余总结：


## 二、通用短视频拆解模块命名词表

### 1. 常见 `模版类型`（按核心目标，可单选或组合）
- `流量类`（赚泛曝光/高完播/高转发）
- `涨粉类`（靠干货/信息差/行业揭秘赚精准关注）
- `人设类`（立专业、真实、暖心或犀利观点形象）
- `引流类` / `种草类` / `带货引流` / `变现类`（筛选高意向受众或促成转化）

### 2. 常见 `呈现方式`（结合故事板抽帧判断）
- `Vlog`、`口播`、`场景化口播`、`口播+画面`、`口播+第一视角画面`、`Vlog+场景化对话`、`画面配音`、`剧情演绎`、`产品展示`

### 3. 常见 `模版结构` 模块名
- **开篇招式**：`高能前置`、`痛点挑衅开篇`、`提出疑问`、`抛出观点`、`颠覆认知`、`好奇开篇`、`背景留悬念`、`事件起因`、`负面现象`、`矛盾冲突`、`自我揭秘`、`圈定人群`、`产品定位`
- **中段推进**：`大范围罗列N`、`痛点行为+绝对指令N`、`同类对比`、`错误做法` / `正确做法`、`负面结果` / `美好结果`、`了解现状`、`深挖故事`、`发现真相`、`专业答疑`、`解决方案`、`自我佐证` / `案例佐证` / `老粉背书`、`事件转折`、`过程过渡`、`套路揭秘` / `套路升级`、`反向论证` / `反向举例`、`罗列卖点N`、`使用方法` / `使用效果`
- **结尾收束**：`得出结论`、`细节暗示成交`、`暖心立人设`、`观点升华` / `价值升华`、`恐惧预警收尾`、`分层给解法`、`方法总结`、`倡导行动` / `关注引导` / `种草引流`

## 三、质量自检红线

1. **模块严丝合缝**：`模版结构` 中用 `+` 连接的每一个模块名，必须与 `拆片演示` 下的编号分段标题**一一对应、顺序完全一致**。
2. **文案真实短句换行**：`拆片演示` 正文必须来自真实转写逐字稿（并对照画面原片字幕校对明显方言/谐音误转），按口语停顿短句硬换行，不加时间戳，对话用双引号标出。
3. **同句式骨架裂变**：`选题裂变` 固定 5 条，必须**精准复用 `模版选题` 的句式结构**做跨行业/跨人群迁移，确保每条都能直接套进上面的 `模版结构` 成立。
4. **按需附加改写**：默认只输出以上 11 字段纯拆解卡；只有当用户明确提出“帮我改写”或“做一个模版嵌套演示”时，才沿用相同 `模版结构` 追加一条示范脚本。
